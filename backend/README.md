# Search Service — Backend API

Backend RESTful API service built with **NestJS**, **MongoDB**, and **Cheerio**.

## Development Setup

```bash
# Install dependencies
npm install

# Start in watch mode
npm run start:dev

# Build for production
npm run build

# Run production build
npm run start:prod
```

## Testing & Quality

```bash
# Run unit tests
npm run test

# Run e2e tests
npm run test:e2e

# Run linter
npm run lint
```
